Arm C — degree-of-interest: the prominence budget as the API term

The mechanism, scoped to what the literature permits: every object's size is tier(x) = max( state_floor(x), focus_tier − hops(x, focus) ) over three discrete tiers — expanded, mid (150×72), floor (76×44). This is Furnas's general form, a combining function monotone increasing in a-priori importance and decreasing in distance; the a-priori term is the prominence budget, entering as a per-object floor rather than an addend, so a card carrying a budgeted state (stale, metadata-possibly, guessable) never compresses below the mid form no matter how far from focus it sits. Positions never change with focus — tiers resize in place, ranks and orderings are fixed — so this is reflow, not distortion, and nothing here is navigation-by-magnification. Measurements and the seven-question table: README.md.

COMMENTARY — OUTSIDE THE RENDER

Host stubs identical to the stress board and to arms A and B; load manifest in ../stress-board/README.md.

What of Furnas is used, and what is refused. Used: the 2006 general form — DOI as some F(API(x), D(x, focus)) monotone in each argument — instantiated as tier = max(state_floor, focus_tier − hops) over three discrete tiers. The prominence budget is the API term, entering as a floor because a budgeted state is a commitment ("this may not shrink below legibility"), not a score to be traded off against proximity. Refused, on the audited record in ../../research/prior-art/focus-context.md: geometric distortion (the field's own review found distortion largely failed to show performance benefit and damages spatial assessment); magnification-as-navigation (target acquisition degrades with magnification precisely because focus movement moves targets — here positions never move, only tier); continuous shrink (the stress board measured uniform scaling dead at ≈0.85×, so tiers are discrete reflowed forms); force-directed re-centering (declined: it is what makes layouts non-deterministic and is the "spring algorithm" family the mental-map literature treats as the hard case — and the Visual Thesaurus, the pattern's popular exemplar, is force-directed re-centering, not DOI, so it is no precedent for any of this). No claim is made that this arm aids comprehension; the literature does not support one. The claim is narrower: state legibility under compression is preserved for budgeted cards, by construction, and that property is checkable in this static file.

Unknowable distance, the behaviour defined. D(x, focus) is hop count over disclosed edges within a component. Three cases have no defined distance, and each gets a stated behaviour rather than a crash or a guess: (1) a blinded edge's destination is not in the domain at all — it has no position, so DOI is never evaluated for it; the edge is drawn to the frontier boundary at every tier of its near node. (2) The frontier region is not at any place: it is excluded from allocation by construction, drawn at fixed size and position at every focus — which the fixed-size anti-leak rule independently requires, since a region that grew or shrank with focus would let marker geometry respond to what hides. (3) Cross-component distance is undefined (no path exists, and none may be manufactured): the max form then has only its first argument, so an unfocused card in another component sits at exactly its state floor — budgeted cards at mid, others at the floor form. A hole has a position (its disclosed in-edge gives it one), so D to a hole is defined; no path is ever counted through a hole, because its out-edges are unknown and a hop count through unknown edges would be invented topology.

Re-layout and the mental map. Focus change alters tiers only: ranks, row order within rank, and left-to-right order are fixed functions of the presentation, so orthogonal ordering is preserved across every focus change — which is the one mental-map property with a proof tradition behind it. Proximity and topology preservation are unsolved in that literature, so nothing in this arm lets proximity carry meaning: the caps say sizes are allocation and distances are packing, and path length is read by counting cards, never by measured distance. If a transition between these two frames is ever animated, the literature supports only a spatial-reconstruction claim, not a comprehension or speed claim, and WCAG 2.1 SC 2.3.3 (Level AAA) requires the motion to be disableable regardless.

Determinism: tiers are a pure function of (presentation bytes, host stubs, focus SAID); hop counts are over committed edges only; orderings are rank then SAID. No seeds, no iteration, no simulation. Byte-identical output on identical input.

Print: a static render has no focus, and the mechanism defines its own degradation: with y absent, F degenerates to its API argument, which is frame C1 — the prominence budget alone deciding size. That is arguably the most honest static form any arm offers: what the page refuses to shrink is exactly what the render-model marked as budgeted, with no interactive residue pretending otherwise. Parameters of non-budgeted cards still need per-card expanded sheets, as in every arm.
