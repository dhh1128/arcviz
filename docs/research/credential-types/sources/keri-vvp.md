# Credential types extracted from KERI/VVP sources

Extraction only — no categorization proposed. Types are recorded as each source names them, verbatim where the source gives a name. `not stated` means the source is silent; `unknown` means the source gives no determinable answer. No dedup across sources (the same type appears under several sources by design).
