Projects

The OpenWallet Foundation is a neutral home for open source projects supporting the development of interoperable digital wallets. Below you will find the Projects and important links to where project activity is taking place.

Currently, we have projects in the Growth and Labs stages of development. You can learn more about the OpenWallet Foundation Project Lifecycle here: https://tac.openwallet.foundation/governance/project-lifecycle/

If you would like to propose a project (Impact, Growth or Labs stage), you can find the project proposal process here: https://tac.openwallet.foundation/governance/project-lifecycle/#project-proposal-process

Previously known as Hyperledger Aries Framework Javascript, Credo initially heavily relied on Hyperledger standards such as DIDComm, Indy, and AnonCreds.

DIDComm Mediator Service

The DIDComm Mediator Service supports mobile DIDComm agents as a reliable intermediary providing an addressable HTTP endpoint for secure message routing.

EUDIPLO

EUDIPLO is a lightweight, open-source middleware layer designed to simplify integration with the European Digital Identity Wallet (EUDI Wallet) ecosystem.

Multipaz

SD-JWT Javascript Reference Implementation

A JavaScript implementation of the Selective Disclosure for JWTs (SD-JWT) specification.

VCX

VCX is an open-source codebase that provides a wide suite of Rust modules for building DID & Aries-related applications (client/mobile and server).

Apostille
